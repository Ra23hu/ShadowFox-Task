My projects

HelioSmart – Dual-Axis Solar Tracking System

  • Designed and built a working 3D prototype of a dual-axis solar panel tracker that rotates 0°–180° both vertically and horizontally to follow sunlight.
  • Programmed motor control logic in C using ESP32 and Arduino Uno for real-time positioning.
  • Developed a web interface (hosted via ESP32) allowing users to control the panel manually or switch to automatic sun-tracking mode.
  • Implemented Wi-Fi based communication between the web dashboard and the hardware for real-time control.
  • ESP32
  • Arduino Uno
  • C++
  • Web Development

  • Integrated an AI chatbot that helps visitors find what they need and makes the site more interactive.
